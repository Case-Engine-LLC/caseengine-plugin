# Statute Review Checklist

Use this checklist when reviewing legal marketing content for accuracy.

## Pre-Review Setup

- [ ] Identify the state(s) covered in the document
- [ ] Identify the practice area (auto, truck, pedestrian, etc.)
- [ ] Note the document creation date (for context on currency)

## Citation Format Review

### California
- [ ] Vehicle Code: `Cal. Veh. Code § [number]`
- [ ] Civil Code: `Cal. Civ. Code § [number]`
- [ ] Code of Civil Procedure: `Cal. Civ. Proc. Code § [number]`
- [ ] Government Code: `Cal. Gov't Code § [number]`
- [ ] Insurance Code: `Cal. Ins. Code § [number]`

### Colorado
- [ ] General format: `C.R.S. § [title]-[article]-[section]`
- [ ] Example: `C.R.S. § 13-21-111` (comparative negligence)

### Florida
- [ ] General format: `Fla. Stat. § [chapter].[section]`
- [ ] Example: `Fla. Stat. § 768.81` (comparative negligence)

### Georgia
- [ ] General format: `O.C.G.A. § [title]-[chapter]-[section]`
- [ ] Example: `O.C.G.A. § 51-12-33` (comparative negligence)

### Maryland
- [ ] Format varies by code: `Md. Code, [Code Name] § [section]`
- [ ] Example: `Md. Code, Cts. & Jud. Proc. § 3-2A-06`

### Texas
- [ ] Format: `Tex. [Code] Code § [section]`
- [ ] Example: `Tex. Civ. Prac. & Rem. Code § 33.001`

### Virginia
- [ ] General format: `Va. Code § [title].[chapter]-[section]`
- [ ] Example: `Va. Code § 8.01-243` (statute of limitations)

## Time Period Verification

### Statute of Limitations

- [ ] Motor vehicle accidents - correct period for state
- [ ] General personal injury - correct period for state
- [ ] Wrongful death - correct period for state
- [ ] Government claims - notice period AND filing deadline

### Discovery Rule Exceptions

- [ ] Note if discovery rule applies (injuries not immediately apparent)
- [ ] Medical malpractice often has different rules
- [ ] Minors typically have tolled periods

## Comparative Negligence Check

- [ ] Correct negligence type for state (pure vs. modified vs. contributory)
- [ ] Correct bar threshold (49%, 50%, 51%, or any fault)
- [ ] Accurate description of recovery reduction formula

## Cross-Reference Verification

For each citation found:
1. [ ] Citation format is correct
2. [ ] Statute exists in database or can be verified
3. [ ] Summary accurately describes the statute
4. [ ] Dollar amounts are current
5. [ ] Time periods are accurate

## Final Checks

- [ ] No obviously outdated information (pre-2024 caps/minimums)
- [ ] Consistent citation style throughout document
- [ ] Related statutes mentioned where relevant
- [ ] Source URLs provided for key citations
