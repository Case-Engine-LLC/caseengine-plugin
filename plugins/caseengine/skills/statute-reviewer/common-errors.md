# Common Statute Errors to Catch

This document lists frequently encountered errors in legal marketing content that reviewers should watch for.

## Recent Law Changes (2023-2025)

### California Insurance Minimums - CRITICAL
**Changed:** January 1, 2025
**Old (WRONG):** 15/30/5 ($15,000 per person, $30,000 per accident, $5,000 property)
**New (CORRECT):** 30/60/15 ($30,000 per person, $60,000 per accident, $15,000 property)

This is the first increase since 1967. Any content written before 2025 will have the wrong numbers.

### Colorado Non-Economic Damage Caps - CRITICAL
**Changed:** January 1, 2025 (HB24-1472)
**Old (WRONG):** $729,790 (standard) / $1,459,600 (enhanced)
**New (CORRECT):** $1,500,000 (personal injury) / $2,125,000 (wrongful death)

### Florida Comparative Negligence - CRITICAL
**Changed:** March 24, 2023 (HB 837)
**Old (WRONG):** Pure comparative negligence (recover at any % fault)
**New (CORRECT):** Modified comparative negligence with 50% bar (no recovery if 51%+ at fault)

This was a major change. Content from before March 2023 will incorrectly describe Florida as a "pure comparative" state.

## Citation Format Errors

### Wrong State Abbreviations

| Wrong | Correct |
|-------|---------|
| CA Civil Code | Cal. Civ. Code |
| FL Stat | Fla. Stat. |
| TX Code | Tex. [Specific] Code |
| CO Rev Stat | C.R.S. |
| GA Code | O.C.G.A. |

### Missing Section Symbol

| Wrong | Correct |
|-------|---------|
| Section 768.81 | § 768.81 |
| Sec. 13-21-111 | § 13-21-111 |

### Informal References

| Wrong | Correct |
|-------|---------|
| "Florida's comparative negligence law" | Fla. Stat. § 768.81 |
| "California's two-year deadline" | Cal. Civ. Proc. Code § 335.1 |

## Statute of Limitations Errors

### Confusing Motor Vehicle with General PI

**Colorado:** Motor vehicle = 3 years, General PI = 2 years
- Wrong: "Colorado has a 2-year statute of limitations for car accidents"
- Correct: "Colorado has a 3-year statute of limitations for motor vehicle accidents (C.R.S. § 13-80-101(1)(n))"

**Florida:** Both are 4 years, but this changed from 2 years
- Verify any content mentioning Florida SOL

### Government Claims Deadlines

These are often missed or confused:
- **California:** 6 months to file government claim
- **Colorado:** 182 days to file government claim
- **Texas:** 6 months formal notice required

## Comparative Negligence Errors

### Bar Threshold Confusion

| State | Correct Threshold | Common Error |
|-------|-------------------|--------------|
| Colorado | 50% (no recovery at 50%+) | Saying 51% |
| Texas | 51% (no recovery at 51%+) | Saying 50% |
| Georgia | 50% | Confusing with Texas |

### Contributory vs. Comparative

**Virginia and Maryland** use contributory negligence (any fault bars recovery).
- Wrong: "Virginia follows comparative negligence"
- Correct: "Virginia follows contributory negligence - any plaintiff fault bars recovery"

### Florida 2023 Change

- Wrong: "Florida is a pure comparative negligence state"
- Correct: "Florida follows modified comparative negligence with a 50% bar (as of March 2023)"

## Dollar Amount Errors

### Outdated Damage Caps

Always verify these numbers - they change:
- Colorado adjusts caps periodically
- Maryland adjusts annual cap for inflation
- California has no cap (don't cite a cap)

### Wrong Insurance Minimums

Each state has different requirements. Common errors:
- Using California numbers for other states
- Using pre-2025 California numbers
- Confusing PIP states (Florida) with traditional liability states

## Practice Area Specific Errors

### Truck Accidents
- Citing only state law when federal FMCSR regulations apply
- Missing hours of service violations (49 C.F.R. § 395)
- Wrong commercial vehicle weight thresholds

### Dog Bites
- Applying strict liability in one-bite rule states (Virginia)
- Missing local breed-specific ordinances
- Wrong notification/quarantine requirements

### Wrongful Death
- Wrong beneficiary hierarchy for state
- Confusing survival action with wrongful death
- Missing cap (Colorado has specific wrongful death cap)

## Federal vs. State Confusion

### Commonly Confused

| Topic | Federal | State |
|-------|---------|-------|
| Trucking regulations | FMCSR (49 C.F.R.) | State commercial vehicle codes |
| Medical leave | FMLA | State family leave laws |
| Disability | ADA | State disability laws |

### When Both Apply

For trucking cases, both apply:
- Federal: Hours of service, licensing, equipment
- State: Speed limits, DUI thresholds, negligence per se

## Verification Resources

When in doubt, verify against:
1. State legislature official website
2. Justia.com statute database
3. FindLaw state law resources
4. State bar association publications

Always note the date of your verification in any review.
