# Legal Content Review Skill

Use this skill when reviewing or editing generated legal marketing content. It provides instant access to the 48 Algorithmic Authorship rules, banned phrases, and formatting standards.

## Quick Reference - Most Critical Rules

### Absolute Bans (Never Use)

| Banned | Use Instead |
|--------|-------------|
| "for example", "for instance" | Integrate examples naturally |
| "maximum compensation/recovery" | "full", "fair", "complete" |
| "expert/expertise/specialist" (for attorneys) | "experienced", "skilled", "knowledgeable" |
| em-dash (—) or double-dash (--) | commas, semicolons, parentheses |
| "in conclusion", "in summary" | Just state the content |
| "navigating the", "legal landscape" | Concrete action verbs |

### Structure Rules

1. **Heading Integration**: First sentence after ANY heading MUST incorporate key words from that heading
2. **Clause Placement**: Move "if/when/because/as" to END of sentences
3. **Bold Usage**: Bold ONLY headings and list labels, NEVER paragraph text
4. **Present Tense**: Use for certain statements ("comes" not "will come")

### Formatting Standards

- **Settlement Ranges**: Start low ($500-$1,000), end with "+"
- **Win Rates**: Range 70-92% depending on case complexity
- **CTAs**: Always italicized: *Contact us today...*
- **Heading Hierarchy**: Never skip levels (H2 → H3 → H4)

## Review Workflow

1. **Check banned phrases first** - fastest way to catch violations
2. **Verify heading integration** - first sentence must reference heading
3. **Scan for formatting issues** - em-dashes, bold misuse, missing CTAs
4. **Validate structure** - settlement ranges, win rates, heading hierarchy
