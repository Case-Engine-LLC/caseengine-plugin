# Formatting & Validation Checklist

Quick reference for validating generated legal content.

---

## Pre-Submission Checklist

### Structure Verification
- [ ] H1 title contains [City] + [Practice Area] + Attorney
- [ ] Introduction summarizes all H2 sections in 2-3 paragraphs
- [ ] Benefits bullet list follows introduction (8-12 bullets)
- [ ] Heading hierarchy is correct (no skipped levels: H2 → H3 → H4)
- [ ] All required sections present in correct order

### Content Verification
- [ ] Attorney names included with specific credentials
- [ ] All numbers in numeric form (15 years, not fifteen)
- [ ] Settlement ranges start low ($500-$1,000) and end with "+"
- [ ] Difficulty levels assigned to all compensation types
- [ ] Win rates included for all accident types (70-92% range)
- [ ] At least 4 unique statistics sourced to specific authority
- [ ] State codes cited correctly (e.g., CVC Section XXXXX for California)

### Formatting Verification
- [ ] All anchor text is bolded (once per term)
- [ ] All CTAs are italicized
- [ ] No bolding in paragraph content (only headings/labels)
- [ ] Tables use consistent structure
- [ ] No em-dashes (—) or double-dashes (--)

### Final Review
- [ ] No competitor mentions
- [ ] City name appears 20+ times
- [ ] Firm name used consistently
- [ ] Disclaimer included in compensation section

## Difficulty Level Guidelines

| Level | Description | Examples |
|-------|-------------|----------|
| **Low** | Easy to prove with documentation | Lost wages with pay stubs |
| **Moderate** | Requires some expert testimony | Rehabilitation costs |
| **High** | Subjective, requires strong evidence | Pain and suffering |
| **Severe** | Complex, long-term proof needed | Permanent disability |
| **Critical** | Extremely hard to win | Punitive damages |

## Heading Level Usage

| Level | Usage | Example |
|-------|-------|---------|
| **H1** | Page title (ONE per page) | Santa Ana Car Accident Attorney |
| **H2** | Major sections (10-15 per article) | Types of Compensation...; Common Causes... |
| **H3** | Subtopics within H2 sections | Lost Wages; Pain and Suffering |
| **H4** | Supporting questions | What Is a Contingency Fee Agreement? |
| **H5** | Deep detail (rare) | How Do Attorneys Secure Dash Camera Data? |

**RULE**: Never skip heading levels (H2 → H4 is wrong)

---

## Content Format Types

| Section Type | Format |
|--------------|--------|
| "What is...?" / "How does...work?" | Paragraph (50-150 words) |
| Multiple items with definitions | List Definition + Headwords |
| Step-by-step instructions | Instructional List + Timeline |
| Compensation type | Compensation Format (w/ difficulty) |
| Injury or accident type | Injury Format (w/ symptoms) |
| State laws/codes | Law Format (table + entries) |

---

## Common Rejection Reasons

1. Wrong format type (bullets where paragraph required)
2. Missing attorney names/credentials
3. Generic content without city/firm specifics
4. Skipped heading levels
5. Missing CTAs in compensation sections
6. Banned phrases present ("for example", "maximum compensation")
7. Em-dashes or double-dashes in content
