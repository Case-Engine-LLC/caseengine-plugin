# Banned Phrases Reference

This document lists all phrases that must NEVER appear in generated content.

---

## Critical Banned Phrases (Automatic Failure)

### Example Introducers
| Banned | Replacement |
|--------|-------------|
| "for example" | Integrate examples naturally into sentences |
| "for instance" | List examples directly after a declaration |

Wrong: "For example, medical bills can accumulate quickly."
Correct: "Medical bills accumulate rapidly, including ambulance transport, diagnostic imaging, and surgical procedures."

### Maximum Compensation Language
| Banned | Replacement |
|--------|-------------|
| "maximum compensation" | "full compensation" |
| "maximum recovery" | "fair compensation" |
| "maximize your compensation" | "the compensation you deserve" |
| "maximize recovery" | "complete recovery" |
| "maximum damages" | "fair damages" |
| "maximum settlement" | "the settlement you're entitled to" |
| "maximizing your" | "recovering your full" |
| "maximizing compensation" | "pursuing fair compensation" |

### Attorney Descriptors
| Banned | Replacement |
|--------|-------------|
| "expert attorney" | "experienced attorney" |
| "expert lawyer" | "skilled lawyer" |
| "attorney expert" | "knowledgeable attorney" |
| "lawyer expert" | "seasoned lawyer" |
| "our experts" | "our attorneys" |
| "legal experts" | "legal professionals" |
| "expertise in" | "experience with" |
| "specialized expertise" | "focused experience" |
| "specialist attorney" | "qualified attorney" |
| "specialist lawyer" | "dedicated lawyer" |

### AI Tell-Phrases
| Banned | Replacement |
|--------|-------------|
| "in conclusion" | Just state the content |
| "in summary" | Just state the content |
| "it's important to note" | State the fact directly |
| "it's crucial to" | State the requirement directly |
| "when it comes to" | Remove and rephrase |
| "navigating the" | Use specific action verbs |
| "navigate the" | "handle", "manage", "address" |
| "comprehensive approach" | Describe specific actions |
| "legal landscape" | "court procedures", "legal requirements" |
| "complex legal" | Be specific about what's complex |

## Formatting Violations

| Banned | Replacement |
|--------|-------------|
| em-dash (—) | comma, semicolon, or parentheses |
| double-dash (--) | comma, semicolon, or parentheses |

Wrong: "Injuries—including broken bones—require treatment."
Correct: "Injuries, including broken bones, require treatment."

## Warning Phrases (Max 3 Per Document)

These are allowed sparingly but fail validation if overused:

| Phrase | Max Occurrences |
|--------|-----------------|
| "such as" | 3 |
| "including but not limited to" | 3 |
| "moreover" | 3 |
| "furthermore" | 3 |
| "additionally" | 3 |

---

## Sentence Starters (Max 2 Per Document)

Move these to the END of sentences:

| Starter | Limit |
|---------|-------|
| "When " | 2 sentences max |
| "Because " | 2 sentences max |
| "If " | 2 sentences max |
| "As " | 2 sentences max |

Wrong: "When you're injured, you need legal help."
Correct: "You need legal help when injuries create mounting expenses."
